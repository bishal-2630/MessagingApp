# Chatme

A full-stack messaging application built with **Flutter Web** (frontend) and **Django REST Framework** (backend), served via **Nginx** inside a Docker container.

## Features
- User registration & login (Token-based auth)
- Send and receive messages in real-time
- Responsive Flutter Web UI

## Tech Stack
- **Frontend**: Flutter Web
- **Backend**: Django + Django REST Framework
- **Proxy**: Nginx
- **Server**: Gunicorn
